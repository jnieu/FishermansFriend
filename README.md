# Fishermans' Friend

A World of Warcraft: Forever addon (interface 16001) that tracks your Fishing skill and catches, with hotkeys to equip a pole and cast.

## Install

1. Copy the `FishermansFriend` folder into `World of Warcraft\_forever_\Interface\AddOns\`.
2. Restart the game. New addon folders are only picked up at startup.
3. On the character screen, open AddOns and make sure Fishermans' Friend is enabled.

## Set the hotkeys

Go to Options > Keybindings > AddOns > Fishermans' Friend and assign:

- **Equip fishing pole**: equips the best pole in your bags.
- **Cast Fishing**: casts your line.

## Commands

| Command | What it does |
| --- | --- |
| `/ff` | Opens or closes the tracker window |
| `/ff status` | Shows skill, detected spell and pole, and totals |
| `/ff skill` | Shows your latest skill changes |

Hover a catch in the window to see which zones you caught it in. Data is saved per character.

If something doesn't work, `/ff status` is the first thing to check.
